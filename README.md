# Student Satisfaction Survey Analysis

A data analysis project exploring the relationship between university life satisfaction, GPA, and perceptions of Konya as a student city, based on a survey of 27 university students.

## Overview

This project was completed as part of a Data Science course during my Computer Engineering studies. It uses Python, Pandas, Seaborn, and scikit-learn to analyze survey responses and identify patterns between academic performance and student satisfaction.

## What's inside

- **Data cleaning & aggregation** — calculating average GPA across participants
- **Data visualization** — word cloud, bar plots, and distribution plots using Seaborn/Matplotlib
- **Correlation analysis** — relationship between university life satisfaction and GPA
- **Linear regression** — predicting satisfaction based on GPA using scikit-learn (train/test split, R², MAE, MSE)

## Tools used

- Python
- Pandas
- Seaborn / Matplotlib
- scikit-learn
- WordCloud
